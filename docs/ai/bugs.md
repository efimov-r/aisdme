# Известные баги

При ошибке сначала искать здесь. Открытые — подробно, решённые — одной строкой.

## Открытые

### Падение при первом запуске без последнего проекта
- **Симптом:** если в глобальном конфиге нет `lastOpenProject` или папка проекта удалена, приложение должно упасть с `NullPointerException` после окна загрузки
- **Где:** `ui/win/AisDmeWindow.kt`, `AppStartState.Ready(config, lastProject!!)`
- **Статус:** открыт; найдено по коду, запуском не проверено. Issue [#2](https://github.com/efimov-r/aisdme/issues/2)
- **Что пробовали:** ничего; нужен выбор проекта при старте (диалог или проект по умолчанию)

### Баги из разбора кода (2026-11-05)
- **Симптом:** список из ~20 пунктов. Самое опасное — потеря данных: при выходе текст вкладки пишется в файл без проверки статуса (файл, который не успел загрузиться, затирается пустой строкой, бинарный портится); rename / move / paste молча перезаписывают существующие файлы
- **Где:** список с путями и строками — в issue [#26](https://github.com/efimov-r/aisdme/issues/26)
- **Статус:** открыт; найдено по коду, запуском не проверено
- **Что пробовали:** ничего
