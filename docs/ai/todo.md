## Проверить руками

Внешние правки открытых файлов ([#9](https://github.com/efimov-r/aisdme/issues/9)) проверены тестами, кроме картинок (для них нет теста: декодер Skia в CI не проверялся). Проверить в приложении на Windows и Linux:

- [ ] Открыть текстовый файл, изменить и сохранить его в другой программе (Блокнот, Kate), вернуться в окно — текст обновился, плашки нет
- [ ] То же при несохранённом вводе во вкладке — статус «changed», плашка; «Load from disk» берёт текст с диска, «Keep mine» перезаписывает файл
- [ ] Удалить открытый файл без правок снаружи — вкладка закрывается; с несохранённым вводом — статус «deleted», «Save again» создаёт файл, «Close tab» закрывает
- [ ] Обычное сохранение из приложения не вызывает плашку; клик в тексте при плашке её не сбрасывает
- [ ] Открытая картинка: заменить файл снаружи — после возврата в окно картинка новая; удалить — вкладка закрывается

Стрелки по дереву при пустом выделении ([#39](https://github.com/efimov-r/aisdme/issues/39), PR [#40](https://github.com/efimov-r/aisdme/pull/40)) проверены только тестами. Проверить в приложении:

- [ ] ↓ при пустом выделении (например, после «свернуть всё») выделяет верхний узел, ↑ — нижний из видимых; приложение не падает

Архитектура [#27](https://github.com/efimov-r/aisdme/issues/27) (PR [#37](https://github.com/efimov-r/aisdme/pull/37)) проверена только тестами. Проверить в приложении:

- [ ] «Split and Move Other Half» последней вкладки слева, когда справа есть вкладки: вкладка не пропадает
- [ ] Закрытие последней вкладки слева: правая половина переезжает в левую без мигания
- [ ] Диалоги New File / New Directory / Paste / Rename с неподходящим выделением — ошибка, диалог не открывается; Delete без выделения — ничего
- [ ] Вырезать несколько узлов — серым помечены все, вместе с содержимым
- [ ] Переключение темы сохраняется после перезапуска

Цвета без `copy(alpha)` ([#11](https://github.com/efimov-r/aisdme/issues/11), PR [#38](https://github.com/efimov-r/aisdme/pull/38)) проверены только сборкой. Проверить в светлой и тёмной теме:

- [ ] Контекстное меню: выделенный пункт, серый хоткей, разделитель — как раньше
- [ ] Наведение на кнопки над деревом и на крестик вкладки — лёгкая зелёная подсветка
- [ ] Drag & drop в дереве: папка-цель подсвечена, как половина редактора при перетаскивании
- [ ] Пустая половина редактора: серая надпись «Drop files here to open them»

## Проверить на Linux

Код для Linux менялся в [#12](https://github.com/efimov-r/aisdme/issues/12) (PR [#29](https://github.com/efimov-r/aisdme/pull/29)) и проверен только по коду. Проверить на Manjaro (KDE), когда будет возможность:

- [ ] `gradlew run` запускается, подхватывается старый конфиг `~/.config/AisDme/config.json` (последний проект, тема, окно)
- [ ] Дерево обновляется, если в Dolphin создать, переименовать и удалить файл и папку на 2–3 уровня вглубь, в том числе внутри только что созданной извне папки
- [ ] В меню дерева пункт называется «Show in Dolphin»; он и Alt+E на файле и на папке открывают Dolphin с выделенным элементом
- [ ] Вырезать в Dolphin → вставить в дереве: оригинал исчезает. Вырезать в дереве → вставить в Dolphin: файл исчезает из проекта. Копирование в обе стороны по-прежнему копирует
- [ ] Вставка папки в её подпапку: ошибка в диалоге Paste, кнопка OK неактивна

Ленивая загрузка дерева и watcher ([#28](https://github.com/efimov-r/aisdme/issues/28), PR [#34](https://github.com/efimov-r/aisdme/pull/34)): на Linux следим только за прочитанными папками, проверено только тестами:

- [ ] Раскрыть свёрнутую папку, затем в Dolphin создать в ней файл — появляется в дереве
- [ ] В Dolphin создать файл в папке, которую ещё ни разу не раскрывали, потом раскрыть её — файл виден
- [ ] Переименовать в Dolphin раскрытую папку, раскрыть её под новым именем, создать в ней файл — появляется в дереве
- [ ] Кнопка «Selected Opened File» над деревом для файла из глубоко свёрнутой папки — папки раскрываются, файл выделен
- [ ] «Expand selected» на папке с вложенными — раскрывается всё; создание файла в глубокой папке видно в дереве
- [ ] Набор текста в редакторе не вызывает `rebuildDirDiff` в логе (нет `ENTRY_MODIFY`)
