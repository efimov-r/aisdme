## Дальше

Главное — быстро редактировать большие текстовые файлы, в том числе вставлять в середину, и отменять ввод. Решение — [decisions.md](decisions.md), «Piece Table + LineIndex + Undo».

- [ ] **Piece Table** вместо всего текста в `TextFieldValue`: два буфера (исходный текст файла и буфер добавлений) и список кусков; при вставке текст не копируется. Соседние куски склеивать, чтобы посимвольный ввод их не дробил
- [ ] **Undo / Redo** поверх Piece Table: история операций `EditOperation` (вставка, удаление), Ctrl+Z и Ctrl+Shift+Z, соседние посимвольные правки объединяются в одну операцию (coalescing); у каждой вкладки своя история; автосохранение историю не сбрасывает
- [ ] **LineIndex** — индекс позиций переводов строк: номер строки по смещению и начало строки за O(log n) двоичным поиском, обновление при вставке и удалении. Для файлов 10 МБ+ — сбалансированное дерево
- [ ] **Отрисовка только видимых строк (viewport rendering)** — чтобы открывать файлы 100 МБ+
- [ ] Реакция на удаление и изменение извне файла, открытого в редакторе
- [ ] Своя панель заголовка окна (custom title bar)
- [ ] Автоскролл при перетаскивании к краю должен останавливаться в конце прокрутки
- [ ] Убрать все `copy(alpha = …)` у цветов
- [ ] Дальше по уровням: инкрементальный разбор (лексер → токены → стили), затем слои отрисовки: подсветка, встроенные подсказки, подчёркивание ошибок, курсор, выделение
- [ ] Проверить сборку и запуск на Windows
